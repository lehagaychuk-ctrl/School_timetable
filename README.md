# Школьное расписание

Локальное приложение директора: редактируемый список классов (изначально 47 заготовок), две смены, расписание по датам, независимые недельные шаблоны, проверки занятости и настоящий экспорт PDF / XLSX / DOCX.

Есть аккаунты с отдельными базами школ, главная со счётчиками, справочники предметов и кабинетов, учебная программа, расписания учителей и кабинетов, правила, автоподбор недели и проверяемый импорт CSV/JSON.

## Аккаунты и школы

Вход и регистрация находятся на `/account`. Первый зарегистрированный аккаунт получает существующую локальную школу со всеми уже введёнными данными. После этого доступ к данным требует входа. Каждая следующая регистрация создаёт отдельную пустую школу, без классов, учителей и расписаний других аккаунтов.

При регистрации укажите организацию, имя, почту и пароль от 10 до 128 символов. Почта служит логином; письма локальное приложение не отправляет. Пароли и коды восстановления сохраняются в виде хешей. Код восстановления показывается один раз при регистрации; сохраните его. Восстановление по коду меняет пароль, выдаёт новый код и завершает старые сессии.

Аккаунты находятся в `data/school.accounts.sqlite3`, существующая школа — в `data/school.sqlite3`, новые школы — в `data/school-schools/<id>.sqlite3`. При резервном копировании всего приложения сохраняйте всю папку `data`. Пароли тестовых аккаунтов в исходном коде и документации не записываются.

## Учебная программа и автоподбор

1. Задайте звонки, классы и преподавателей. В карточках учителей укажите предметы, рабочие классы, доступность и пределы нагрузки.
2. В «Справочники» проверьте предметы и кабинеты. Уже использованные названия собираются из существующих карточек и расписаний. Записи можно добавлять, переименовывать и архивировать. Переименование обновляет сохранённые занятия и карточки учителей.
3. В «Учебная программа» добавьте строки: класс, предмет, учитель, недельные часы и, если нужно, допустимые кабинеты. Учитель должен быть назначен выбранному классу и предмету.
4. В «Правила» задайте учебные дни, пределы уроков класса и предмета на день. Пустой предел не добавляет ограничений. По умолчанию разрешены все дни, чтобы новая настройка не меняла существующее расписание.
5. В «Автоподбор» выберите неделю и сформируйте предложение. Существующие занятия сохраняют места. Учитываются недельные шаблоны для дат без сохранённого расписания, занятость по фактическому времени обеих смен, часы работы, пределы учителя, класс и кабинеты. Подбор размещает оставшиеся часы последовательным выбором подходящих ячеек; это не гарантия нахождения всех возможных вариантов. Неразмещённые часы показываются с причинами.
6. После просмотра нажмите «Применить предложенные уроки». До этого расписания не меняются. Если данные изменились после расчёта, применение блокируется до нового предпросмотра. Запись недели выполняется целиком в транзакции и повторно проверяется на новые конфликты.

«Расписание учителей» и «Расписание кабинетов» показывают занятия дня или недели. Дни из недельных шаблонов помечаются отдельно. Главная показывает реальные количества классов, преподавателей, кабинетов, предметов, часов программы, размещённых уроков, оставшихся часов программы и нарушений выбранной даты.

«Импорт» принимает CSV по скачиваемым шаблонам или JSON-массивы классов, учителей и учебной программы. Значения `subjects`, `rooms`, `classes` можно перечислять через запятую. Сначала выполняется проверка всего файла, затем отдельной кнопкой записи добавляются атомарно; существующие имена пропускаются. В этом же разделе скачивается JSON-копия данных текущей школы без аккаунтов и паролей. Для восстановления всех данных сохраняйте исходные базы SQLite из папки `data`.

## Запуск в Windows

Откройте `start.bat` двойным щелчком. Приложение доступно по адресу **http://127.0.0.1:8765**. Окно сервера оставьте открытым. Для остановки нажмите Ctrl+C.

Повторный запуск открывает уже работающий экземпляр. Защита от нескольких серверов на одном порту предотвращает смешивание версий интерфейса. После обновления файлов перезапустите сервер и нажмите Ctrl+F5 в браузере; при несовпадении версий приложение показывает понятное сообщение с этими действиями.

Скрипт ищет Python 3.12+ в `.venv`, PATH и установленном LibreOffice. Можно явно указать путь через переменную `TIMETABLE_PYTHON`. Библиотеки устанавливаются только в `.vendor` проекта. На этом компьютере зависимости уже установлены. Запуск без открытия браузера: `powershell -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser`.

Обычный запуск с самостоятельно установленным Python:

```powershell
python -m pip install -r requirements.txt
python app.py
```

## Работа

1. В «Классы и смены» замените 47 заготовок реальными названиями, назначьте смены и порядок печати. Новые классы добавляются кнопкой «Добавить класс»: укажите название и смену, затем нажмите «Добавить и сохранить». При этом сохраняются и текущие правки остальных классов. Начальные смены 24/23 — редактируемые заготовки, а не данные вашей школы. Уроков в базе изначально нет.
2. В «Шаблоны печати» нажмите «Заполнить по образцу», чтобы получить оформление по присланным фотографиям: альбомный A4, серые шапки, тонкую чёрную сетку, компактные строки, предмет и кабинет в одной ячейке. Задайте школу, директора и реальные звонки обеих смен, затем сохраните. Кнопка сохраняет введённые в форму реквизиты школы и не меняет звонки.
3. Выберите дату. Нажмите свободную ячейку: откроется конструктор с выбранным классом и уроком. Выберите доступного учителя, его предмет и кабинеты, затем добавьте урок. Нажатие на заполненную ячейку открывает редактор; в нём можно добавить до четырёх подгрупп, переставить урок или отметить отмену.
4. Урок сохраняется сразу. Примечания сохраняйте кнопкой «Сохранить день»; при переходе к другой дате, копированию, утверждению и экспорту они сохраняются автоматически.
5. Кнопкой «Выбрать шаблон расписания» выберите сохранённый день или недельный шаблон любого дня недели. Недельный шаблон обновляется только отдельной кнопкой. Копирование заменяет расписание целевой даты.
6. Проверьте список ошибок. В «Документы и печать» сформируйте PDF, затем скачайте PDF, Excel или Word. Можно выбрать смену, обе смены, все классы или один класс. Предпросмотр всегда показывает настоящий текстовый PDF. В Excel используются листы «1 смена» и «2 смена».

Переключатель «Подсказки» вверху страницы включает и отключает инструкции по текущему разделу и поясняющие блоки. Выбор запоминается в этом браузере после перезагрузки страницы. Ошибки и предупреждения проверки расписания остаются видны.

Кнопка «Выбрать шаблон расписания» в расписании дня открывает список сохранённых дней с датами, количеством уроков и классов. Можно выбрать и недельный шаблон любого сохранённого дня недели. Применение заменяет уроки и примечания выбранной даты самостоятельной копией, снимает утверждение и проверяет конфликты на новую дату. Расписание источника продолжает храниться отдельно. Перед заменой в окне указаны дата назначения и количество заменяемых записей.

Новый класс доступен в конструкторе, печати и списке классов карточки учителя. Отметьте его в карточках учителей, которые с ним работают, и задайте нужную нагрузку.

### Печать по фотографиям

Готовый шаблон «По образцу — компактные таблицы» доступен в «Шаблоны печати». Смены начинаются с отдельных страниц. Заголовок с датой и сменой расположен по центру, утверждение — справа. По умолчанию в этом оформлении утверждение выводится только для первой смены, а номера страниц отключены; оба параметра можно изменить.

В поле «Таблица печати» раздела «Классы и смены» задайте одинаковую метку классам одного блока. Например, метка «Старшие» объединяет 10-е и 11-е классы, а «5-е и инженерный» — пятые и выбранный инженерный класс. Название метки служит для группировки и не добавляется в печатный заголовок. При пустой метке включённая настройка «Отдельная таблица для каждой параллели» группирует классы по числу в начале названия. Число столбцов ограничивается параметром «Классов в одной таблице», короткие таблицы располагаются по центру. Идентификаторы классов и привязка уроков сохраняются.

В расписании дня добавляйте «Объявления перед таблицами»: выберите любой класс нужного блока и введите текст. Он появится над соответствующей таблицей полужирным шрифтом по центру. Эти объявления сохраняются вместе с датой, копируются с расписанием дня и в недельный шаблон. Примечания к сменам размещаются под общим заголовком.

PDF содержит текст и векторные таблицы. В Word остаются редактируемые таблицы с серыми шапками. В Excel используются редактируемые объединённые ячейки на мелкой сетке: так таблицы с разным числом классов сохраняют собственную ширину на одном листе. Содержимое не обрезается: высота строк растёт по тексту, большие таблицы продолжаются на следующих страницах с повторением шапки.

## Данные и проверки

### Каталог учителей и конструктор

В разделе «Каталог учителей» сохраняются ФИО, несколько предметов, кабинеты по умолчанию и примечание. Учителей можно искать по ФИО или предмету, редактировать, отправлять в архив и восстанавливать.

Чтобы составлять расписание из каталога, нажмите на карточке «Использовать в расписании» или откройте раздел «Конструктор». Выберите дату, класс и номер урока. Программа покажет доступных учителей, работающих с этим классом, и их нагрузку. Выберите преподавателя и предмет, проверьте кабинеты и нажмите «Добавить урок в расписание». Справа видны уже назначенные уроки класса. Также конструктор открывается нажатием свободной ячейки основной таблицы.

В карточке учителя отметьте классы, в которых он работает. Можно задать общую нагрузку на неделю, предел уроков в день и количество уроков в неделю для каждого класса. Это числа учебных занятий, а не астрономические часы. Пустое поле нагрузки означает отсутствие заданного предела; ноль запрещает новые назначения в соответствующем периоде.

Включите «Ограничить доступность рабочими часами» и укажите интервалы для каждого дня недели. Например: `08:00–13:00; 14:00–17:00`. Урок должен целиком помещаться в один рабочий интервал; перерыв исключается. Пустой день — выходной. Для новой карточки форма предлагает понедельник–пятницу 08:00–18:00; измените эти значения под реальное рабочее время.

В конструкторе «Показывать недоступных учителей» раскрывает причины отказа: класс не назначен, нерабочее время, занятость другим уроком, исчерпанная недельная нагрузка или предел на день. Пересечения проверяются по времени обеих смен, включая подгруппы. Проверка повторяется при добавлении урока, поэтому устаревший список не позволяет назначить уже занятого учителя. Занятые кабинеты по умолчанию не подставляются; можно указать другой кабинет.

Вкладка «Ведёт урок» показывает занятых в выбранное время учителей: класс, предмет, номер урока, время, смену, кабинеты и подгруппу. Показываются фактические пересечения интервалов, в том числе между разными номерами уроков обеих смен. Отменённые занятия не учитываются. Если учитель находится в архиве, его сохранённые занятия тоже видны с соответствующей отметкой. Красная подсветка выбранного урока располагается внутри строки с отступом от номера и времени.

Нагрузка считается за понедельник–воскресенье: для дат с сохранённым расписанием берутся их уроки, для остальных дат — соответствующий недельный шаблон, если он есть. Сохранённый пустой день отменяет применение недельного шаблона на эту дату. Отменённые уроки не учитываются. Конструктор запрещает превышение заданных пределов; после ручных правок нарушения отображаются как критические ошибки и блокируют утверждение и официальный экспорт. Черновик остаётся доступен.

В обычном редакторе урока и каждой подгруппы поле «Преподаватель» предлагает ФИО из каталога. Предметы выбранного учителя доступны в подсказках. Кабинеты и единственный предмет подставляются только в незаполненные поля, поэтому замена учителя сохраняет уже введённый кабинет и предмет.

Учитель связан с уроками по постоянному идентификатору. Переименование обновляет ФИО в сохранённых днях, недельных шаблонах и экспорте, снимая утверждение затронутых дней. Изменение кабинетов и предметов в карточке меняет подсказки для новых уроков; существующие занятия сохраняют свои предметы и кабинеты. Архивирование сохраняет уроки и выводит предупреждение о преподавателе из архива.

При первом запуске обновлённого приложения уже введённые учителя автоматически переносятся из расписаний и недельных шаблонов в каталог. Для ранее созданных карточек рабочие классы собираются из сохранённых уроков; проверьте и дополните их в каталоге. Часы работы и нагрузка автоматически не выдумываются. Перед обновлением существующей рабочей базы создаётся копия в `data/backups`. Для применения обновления перезапустите сервер и обновите страницу браузера.

- SQLite: `data/school.sqlite3`. Даты и недельные шаблоны хранятся отдельно. Для резервной копии остановите сервер и скопируйте папку `data`.
- Проверки сопоставляют реальные интервалы времени, включая разные номера уроков, обе смены и подгруппы. Кабинеты и имена сравниваются без учёта регистра и лишних пробелов. Разные варианты написания одного ФИО следует унифицировать.
- Отсутствие учителя или кабинета — предупреждение; пересечения, отсутствие предмета, отсутствие времени урока и пустое расписание — критические ошибки.
- Критические ошибки блокируют утверждение и официальный экспорт. Черновик с ошибками содержит «ЧЕРНОВИК — ЕСТЬ ОШИБКИ» во всех форматах. Проверяется весь день, даже при экспорте одного класса.
- Изменения уроков, звонков, классов или шаблона снимают утверждение. Конкурирующие сохранения одного дня защищены счётчиком версии; при конфликте приложение предлагает обновить страницу.
- При сокращении числа звонков сохранённые уроки не удаляются: в черновике выводятся с пометкой «Время не задано». Официальный экспорт блокируется до исправления.
- PDF использует текст и векторные таблицы, Word и Excel — редактируемые ячейки. Таблицы делятся по целым строкам, шапки повторяются. Высота строк растёт по содержимому. Очень широкие блоки при необходимости делятся на меньшие. Если один урок физически превышает страницу, выводится объяснение вместо обрезанного файла.
- Excel и Word могут немного иначе переносить текст и страницы после редактирования или при других установленных шрифтах. PDF является точным образцом печатного результата.

Приложение предназначено для работы на одном компьютере и слушает только `127.0.0.1`. Вход защищает локальные школы и разделяет данные аккаунтов; публикация в сети в эту версию не входит. Доступа к внешней базе школы не предоставлено: экспорт читает фактические сохранённые данные локальной SQLite, без демонстрационных уроков.

Предпросмотр использует локально включённый PDF.js от Mozilla (версия и лицензия в `static/vendor`). После установки зависимостей приложение и формирование файлов работают без подключения к интернету.

## Шрифты и параметры

Windows PDF использует Times New Roman из системной папки шрифтов. Linux поддерживает DejaVu Serif и Liberation Serif. Для другого пути задайте `TIMETABLE_FONT` и необязательный `TIMETABLE_FONT_BOLD` (TTF с кириллицей). Word и Excel используют Times New Roman. `TIMETABLE_DB` меняет путь базы, `PORT` — порт.

## Проверки

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

Проверки используют временную базу, проверяют независимость дат и шаблонов, конфликты, отмены, блокировки, все 47 классов и извлекаемый текст PDF, а также ячейки и XML файлов Office.

Дополнительные проверки Windows: `python tests/browser_check.py` запускает установленный Edge без окна, проверяет работу редактора и реальные скачивания, оставляя скриншоты и проверочные файлы в `test-output`. Затем `python tests/office_check.py` открывает проверочные Excel и Word через LibreOffice, сопоставляет страницы и сохранность текста с PDF. Эти проверки используют отдельную временную базу и не записывают тестовые уроки в рабочую базу.

`python tests/constructor_browser_check.py` проверяет форму классов, часов работы и нагрузки, подбор недоступных учителей и добавление уроков через конструктор. `python tests/startup_check.py` проверяет запуск и понятную обработку несовпадения версий страницы и сервера.

`python tests/workspace_browser_check.py` проверяет добавление класса, сохранение правок списка, отклонение повторного названия, запоминание переключателя подсказок, выбор сохранённого дня и недельного шаблона, а также расположение элементов на телефоне.

`python tests/reference_browser_check.py` проверяет оформление по образцам на отдельной временной базе: четыре таблицы первой смены и две второй, объявления, группировку, предпросмотр PDF и открытие редактируемых Word/Excel в LibreOffice. Проверочные файлы и изображения страниц сохраняются в `test-output/reference-*` и не содержат данных рабочей базы.

`python tests/accounts_browser_check.py` проверяет регистрацию, вход и выход, изоляцию школ, справочники, программу, правила, предпросмотр и применение автоподбора, расписания ресурсов, импорт и счётчики главной. Все проверки выполняются на временных базах.
